Estou criando uma nova skill para agentes que ajudará Gerentes de Produto, Donos de Produto, Líderes Técnicos e Stakeholders, Engenheiro de requisitos, Gestores de projetos, todos seniores, a criar projetos usando uma estrutura simples.
Essa skill deve incluir todas as etapas de um projeto criado com base no Scrum e conter definições de sequência claras.
Como referência, trabalharemos com as especificações do Ciclo de Vida do Produto (TLC). Essa skill é uma das mais abrangentes para engenharia de software. Aqui está o link:
https://agent-skills.techleads.club/tlc-spec-driven/
Essa skill não cria documentos imediatamente. Primeiro, realiza uma pesquisa de descoberta, identifica lacunas, calcula o score de complitude, questiona os pontos críticos e só prossegue com o documento final quando tiver informações suficientes.
Abaixo está a estrutura final:
- Resumo Executivo - Descoberta
- Meta SMART
- Processos de Negócio
- Detalhes do Projeto
- Regras de Negócio
- Requisitos Funcionais
- Critérios de Aceitação
- Histórias de Usuário
- Requisitos Não Funcionais
- Dependências
- Riscos
- Matriz de Rastreabilidade
- Pontuação de Prontidão
